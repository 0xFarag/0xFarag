Evidence Workbench

Belege prüfen

Öffnen Sie eine Belegquelle, prüfen Sie einzelne Fälle und dokumentieren Sie Ihren Entscheid für die Übergabe.

Lokale SitzungDateien und Notizen bleiben beim Prüfen in diesem Browserfenster.

Öffnen Sie den Signalbericht blue-evidence.json aus AuthzLedger Studio oder der CLI direkt hier. Für Werkzeugexporte erstellen Sie zuerst im lokalen Belegimport einen Belegindex. Hier öffnen Sie den Index, Befund B, Retest C oder ein föderiertes Inventar. Maximal 2 MiB pro Datei.

Das Retest-Beispiel wird geöffnet.

Quelldateien und Originalbytes prüfen

Wählen Sie die Originalexporte zum lokalen SHA-256-Abgleich. Die Workbench liest bis zu 1 MiB je Datei. Das Ergebnis bleibt in dieser Sitzung und ist im exportierten Review nicht enthalten.

      Fallauswahl

        Technische Belege anzeigen

        Eingabedateien für Studio oder CLI Retest-Beleg (JSON)Kontrollsignale (JSON) Erzeugter Signalbericht (JSON)
        Beispiel mit der lokalen CLI erzeugen

        Legen Sie beide Eingabedateien in denselben Ordner und führen Sie dort diesen Befehl mit der installierten SOC-Erweiterung aus.

        python -m authzledger assessment blue-evidence mixed-c-result.json blue-evidence-signals.json --out blue-evidence.json

        Die Bearbeitung verändert den fachlichen Befund nicht. Sichern Sie Ihre Notizen lokal, bevor Sie dieses Fenster schliessen.

        Übergabe

        Redigierte Fallübersicht

        Enthält Prüfergebnis, Bearbeitungsstand und Datei-Fingerabdruck. Signalberichte enthalten die Alarmabdeckung je Probe. Bei Belegindizes enthält die JSON-Übersicht Werkzeug, Quelldigest und Datensatzverweis. Dateinamen, Original-IDs und Freitext bleiben privat. Die Übersicht ist unsigniert.
