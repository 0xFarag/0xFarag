# Feedback and contributions

AuthzLedger is a pre-release with rights reserved, not an open-source project. Consult [LICENSE](LICENSE) and arrange any required permission before submitting code.

Use GitHub issues for non-sensitive bug reports and documentation feedback. Include the version, operating system, Python version, expected behaviour and a minimal reproduction with synthetic data. Do not upload access tokens, customer records, private endpoints or unredacted operational reports.

Report security problems through the private route in [SECURITY.md](SECURITY.md), not a public issue.

For an authorised development copy, run `python3 -m unittest discover -s tests -v` and the local demo in [INSTALL.md](INSTALL.md). Neither needs a remote target.
