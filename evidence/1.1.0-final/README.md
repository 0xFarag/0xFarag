## Reading the receipts

Receipt commands and paths preserve their original absolute execution context. The listed browser artifact hashes may include transient outputs not retained in this compact source evidence; acceptance receipts and release proof files are retained. Source inventories bind product, test and checking code; documentation, artwork and final receipts can be assembled afterward without claiming a self-referential commit hash. Remote CI must pass for the final commit containing these files.

Signatures establish integrity relative to the supplied trusted public key. The main verifier also checks supported retained semantics. Neither proves truthful remote execution, operator identity, trusted time or universal authorization coverage.
